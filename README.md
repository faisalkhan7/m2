# MonoTrader v7

Navigateur dédié au terminal MT5 web (web.metatrader.app) :

- **Noir et blanc natif** sur la fenêtre MT5 uniquement (TradingView reste en couleur en split-screen)
- **Rideau P&L** : le bas de l'écran est masqué, avec un aperçu toutes les X secondes ; une touche sur le rideau l'ouvre 5 s
- Bouton ⚙ (bord droit) : noir et blanc, rideau, intervalle, durée de l'aperçu, hauteur, adresse du terminal
- La page n'est pas rechargée quand on redimensionne le split-screen ; l'écran reste allumé

L'APK est construit par GitHub Actions (onglet Actions → dernier build → artefact).
